# VM Admin Custom Tools
A **Joomla system plugin** that enhances the **VirtueMart backend** (specifically the *Custom Fields* tab) by grouping and collapsing related fields for a cleaner and more efficient product editing experience.

---

**VM Admin Custom Tools** improves the usability of VirtueMart by automatically grouping and collapsing repeated **Custom Fields** when editing a product.

Groups can be expanded or collapsed individually or all at once using “Open all / Close all” buttons.  
The layout is built with **UIkit** to match the VirtueMart backend style.

### Features
- Auto-collapse/expand grouped custom fields  
- “Open all / Close all” global toolbar  
- Optional state persistence (session or permanent)  
- Auto-close other groups when a new one opens  
- Integrated **UIkit chevron icon** on each group header  
- Multilingual (English / Italian)  
- Works **only** with the **VMAdmin** backend template  

### Compatibility
| Component     | Version       |
|----------------|----------------|
| **VirtueMart** | 4.4.0 → 4.4.10+ |
| **Joomla**     | 3.10, 4.x, 5.x  |
| **Template**   | VMAdmin (required) |

### Installation
1. Install the ZIP from **Extensions → Install**  
2. Enable it under **Extensions → Plugins → System - VM Admin Custom Tools**  
3. Open **VirtueMart → Products → Edit → Custom Fields**  
4. Groups will appear collapsible with buttons to open or close them all.

---

## Descrizione

**VM Admin Custom Tools** migliora l’interfaccia di amministrazione di VirtueMart semplificando la gestione dei **Campi Personalizzati (Custom Fields)**.  
Durante la modifica di un prodotto, i gruppi di campi vengono visualizzati come sezioni **collassabili** con icone UIkit e pulsanti globali.

### Funzionalità
- collasso automatico dei gruppi di campi personalizzati  
- Toolbar “Apri tutti / Chiudi tutti”  
- Memorizzazione stato aperto/chiuso (sessione o persistente)  
- Chiusura automatica dei gruppi precedenti  
- Icona UIkit `chevron-right` nel titolo del gruppo  
- Multilingua (Italiano / Inglese)  
- Funziona **solo** con il template **VMAdmin**
